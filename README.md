Компания: «Здоровье+» — федеральная сеть частных клиник (15 филиалов в 5 городах). Штат — 200 врачей, 50 администраторов. Клиентская база — 100 000+ активных пациентов.

Текущие системы:

Сайт и мобильное приложение (React / React Native) — для записи, просмотра результатов анализов, онлайн-оплаты.

CRM (на базе Salesforce или самописная) — управление взаимодействием с клиентами, история обращений, маркетинг.

ERP / Учетная система (1С или аналоги) — управление финансами, запасами медикаментов, расчет зарплаты.

MES-подобная система для управления потоками пациентов — запись к врачам, управление очередями, расписанием кабинетов.

Единая база данных — PostgreSQL как основное хранилище транзакционных данных (пациенты, визиты, диагнозы, назначения).

Архитектура: Микросервисная. Взаимодействие синхронное (REST/gRPC) и асинхронное (Kafka для событий — «пациент записался», «визит завершен», «результат анализа готов»). Для сложных транзакций используется паттерн Saga (хореография или оркестрация). Для чтения и аналитики — CQRS с отдельной read-моделью в NoSQL (MongoDB или Elasticsearch).
